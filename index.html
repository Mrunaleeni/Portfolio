Real-Time NLP Sentiment Pipeline · 17 NSE Stocks

Fetches daily financial news for 17 Indian large-cap stocks via GNews API, scores headlines using FinBERT, and tests whether sentiment predicts same-day or next-day returns. The Streamlit dashboard shows a plain-English verdict — signal detected / too early to tell / no signal — with p-values, sample size progress, and Pearson & Spearman correlation. Includes a GitHub Actions workflow that updates the dataset daily automatically.
